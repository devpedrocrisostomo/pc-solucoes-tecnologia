# Política de segurança — PC Solutions

Relatos de vulnerabilidades do site institucional devem ser encaminhados de forma privada para devpedrocrisostomo@gmail.com com assunto «Relato de Segurança — PC Solutions».

Informe URL afetada, comportamento observado, possível impacto e formas seguras de reprodução. Não realize ações destrutivas, acesso a informações de terceiros ou testes de indisponibilidade. Não há programa de recompensas ou autorização implícita para pentest.

A página pública `/seguranca` contém mais informações. Projetos de terceiros apresentados no portfólio são independentes.
